# Project rules

This is a C++ application for Nintendo Switch running Atmosphere with:

- The Sysmodule backend in `/sysmodule`
- The Tesla Overlay in `/overlay`
- The documentation is in `/docs`
- The public binaires are in `/pub`

## Coding Standards

- Use C++-21 for all new files
- Follow the existing naming conventions
- Write comments and commits in english language even if the prompt is in another language

## Chat rules

- Respond in the same language as the prompt's
