# Project rules

This is a C++ application for Nintendo Switch running Atmosphere with:

- The Sysmodule backend in `/sysmodule`
- The Tesla Overlay in `/overlay`
- The documentation is in `/docs`
- The public binaires are in `/pub`

## Coding Standards

- Use C++-21 for all new files
- Follow the existing naming conventions

## Chat rules

- Respond in the same language as the prompt's

## Documentation standards

- Write docmuentation, comments and commits in english language even if the prompt is in another language.
- Update the documentation in /docs and the Doxygen comments of the source code up to date when applying changed.
- The Doxygen documentation must be written only in the implementation files unless the function is encoded in the header file.
